# AidEthos

AidEthos is an AI-powered volunteer and NGO coordination platform that uses TF-IDF and cosine similarity for intelligent skill-based matching and urgency-aware crisis prioritisation.

## Tech Stack
- FastAPI
- SQLite
- scikit-learn
- HTML/CSS/JavaScript

## Features
- AI-based volunteer matching
- NGO crisis posting
- Urgency-based ranking
- Volunteer dashboards
- Real-time matching system
